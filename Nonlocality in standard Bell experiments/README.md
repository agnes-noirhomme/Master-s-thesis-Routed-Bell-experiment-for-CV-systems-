This part focuses on certifying nonlocality for the two-mode squeezed vacuum state (TMSV), the NOON (N=2) state, and their amplified versions obtained using heralded amplifiers, which can improve the robustness to photon loss. In particular, the measurement scenarios involve rotated quadrature and photon-number measurements, whose outcomes are discretised into two results. The names of the Python files are of the following: XX...-XN... : the first letters are related to Alice's measurements, while the other ones are related to Bob's measurements, such that X corresponds to the rotated quadrature and N, the photon-number measurement.
