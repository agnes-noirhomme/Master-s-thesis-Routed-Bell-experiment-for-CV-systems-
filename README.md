# Master-s-thesis-Routed-Bell-experiment-for-CV-systems-
This repository contains all of the code in Python used for my Master's thesis in quantum information theory: Routed Bell experiments for continuous-variable quantum systems. 
The first part contains a linear program for certifying nonlocality in standard Bell experiments. The second and third parts contain a semidefinite program based on the NPA hierarchy for certifying quantum correlations and quantify photon-loss robustness, in routed Bell experiments.
