# Master-s-thesis-Routed-Bell-experiment-for-CV-systems-
This repository contains all of the code in Python used for my Master's thesis in quantum information theory. 
The first part contains a linear program to certify nonlocality in standard Bell experiments. The second and third parts contain a semidefinite program with NPA hierarchy to certify quantum correlations and quantify photon loss, in routed Bell experiments.
